# Diseño

## Paleta

| Token | Hex | Uso |
|-------|-----|-----|
| magenta | `#E91E8C` | Acentos, CTAs, títulos secundarios |
| amarillo | `#F5D000` | Destacados, números, relleno energía |
| cian | `#00B4C8` | Acentos secundarios, 2026 |
| negro | `#0A0A0A` | Texto, bandas de día |
| blanco | `#FAFAFA` | Fondo contenido |

## Tipografía

- Titulares: Anton / Bangers
- Acentos festivos: Amatic SC
- Cuerpo: sans condensada legible (p. ej. system + Barlowe Condensed o similar vía Google Fonts)

## Assets

- Escudo: `public/escudo.svg` (origen: Escudo_de_Hontoria_de_la_Cantera_(Burgos).svg)
- Atmósfera: salpicaduras CSS, banderines; estética rock/verano del PDF

## Layout

- Hero a sangre: marca Hontoria de la Cantera + Fiestas de Verano 2026 + 2 CTAs
- Escudo en header y footer
